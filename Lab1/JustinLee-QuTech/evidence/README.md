# Live console evidence

Captured on 19 October 2026 from the actual .NET 10.0.401 console process through a local PTY and xterm.js terminal. Browser keyboard actions were sent to the running process. Images are full-page captures of the live terminal, with inputs echoed by the process/terminal. They are not a replay or rendered test log.
